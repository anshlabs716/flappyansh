# Testing

This page describes how Flappy Ansh is tested and how to run the tests yourself.

## Running the tests

```bash
# Manual play testing (see docs/testing.md)
```

## What is covered

Manual play testing. There is no automated test suite.

## Adding tests

- Add tests alongside the code they cover.
- Prefer testing behavior over implementation details.
- Keep fixtures free of real personal data, keys, or credentials.

## Current status

Automated test coverage is a work in progress. Contributions that add tests are
welcome.
